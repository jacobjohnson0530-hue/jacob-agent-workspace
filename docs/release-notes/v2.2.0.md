## 2.2.0 Jacob Agent Workspace derivative bootstrap

The first Jacob Agent Workspace release line separates product identity from the upstream Chat On Steroids project while preserving its existing local-agent and Chrome companion capabilities.

### Changed

- Product/package identity is now **Jacob Agent Workspace** / `jacob-agent-workspace`.
- Core, Desktop and Plugins MCP server identities use the `jacob-agent-workspace-*` namespace.
- Electron application ID, executable names and release artifacts use the derivative identity.
- Update checks and extension recovery target `jacobjohnson0530-hue/jacob-agent-workspace` releases.
- Chrome companion branding is updated across bundled locales without removing its permissions or browser-control features.
- Release and publish workflows now produce `Jacob-Agent-Workspace-*` artifacts.

### Compatibility

The inherited browser bridge wire token `chat-on-steroids`, selected `CLF_*` / `COS_*` / `cos.*` identifiers, and migration-sensitive storage keys remain unchanged in this initial derivative. See `IDENTITY-MIGRATION.md`.
